# PréMold — Gestão de Produção

Sistema offline de gestão de produção de pré-moldados.

## Acesso
[**Abrir o sistema →**](https://SEU-USUARIO.github.io/premold/)

## Funcionalidades
- Cadastro de insumos, produtos e receitas
- Registro de produção com cálculo automático de custo
- Controle de estoque
- Rateio automático de despesas por peça produzida
- Relatórios de consumo, lucratividade e lançamentos
- Exportar CSV e backup JSON
- Funciona offline (dados salvos no navegador)
